# التشغيل والاستمرار

يعمل مُحاور اليوم بلا تكلفة: خادم مجاني، ونموذج مفتوح بحصة مجانية، ولكل اعتماد حرج بديل جاهز. وأكبر قيد هو حصة النموذج المجانية.

## المكونات والبدائل

| المكون | الأساسي | البديل عند تعطله | التكلفة الحالية |
|---|---|---|---|
| الخادم | Oracle Cloud، الطبقة المجانية الدائمة، الرياض (2 OCPU، ذاكرة 12 GB) | Render، الخطة المجانية (512 MB، تنام عند الخمول فتُبقيها مهمة GitHub Actions مستيقظة) | 0 |
| النموذج اللغوي | gpt-oss:120b عبر Ollama Cloud | Gemini (الطبقة المجانية) ينتقل إليه النظام تلقائيًا | 0 ضمن الحصص المجانية |
| بيانات المصادر | الموسوعة القرآنية، وhadith-api، وOpenITI، تُنزَّل عند بناء القاعدة | تبقى القاعدة المبنية تعمل إن تعذر التنزيل | 0 |
| شهادة HTTPS | Caddy وLet's Encrypt، باسم sslip.io | Render يوفر HTTPS تلقائيًا | 0 |

## حصة النموذج (مقيسة)

- في أيام الاختبار استُعمل نحو 2,900 طلب، أي 77.9% من الحصة المجانية الشهرية في Ollama، فالحصة نحو 3,700 طلب في الشهر.
- السؤال الواحد يستعمل نحو 10–20 طلبًا: فهم الرسالة، والكتابة، وقراءة ثانية لكل جملة، والحكم على الصلة، وأحيانًا إعادة الكتابة.
- فالحصة المجانية تكفي نحو 185–370 سؤالًا في الشهر (تقدير من القياس). وما زاد عليها يذهب إلى Gemini، وحصته المجانية تتجدد يوميًا.
- للاستعمال الأوسع: خطة مدفوعة في Ollama أو Gemini بحسب أسعار كل مزود، مع سقف إنفاق شهري يضعه المشغّل.

## إن تعطل شيء

| العطل | ما يحدث |
|---|---|
| تعذر الوصول إلى النموذجين | يقول مُحاور «الخدمة غير متاحة مؤقتًا» ولا يعرض شيئًا غير مفحوص |
| توقف خادم Oracle | يُستعمل رابط Render، والكود نفسه على الخادمين |
| نفاد حصة Ollama | ينتقل تلقائيًا إلى Gemini |
| تعذر فحص الجواب | لا يُعرض الجواب (الفحص يفشل مغلقًا) |

## الصيانة

| متى | ماذا |
|---|---|
| بعد كل تعديل | تشغيل الاختبارات الآلية، ثم على الخادم: `git pull` وإعادة تشغيل الخدمة |
| أسبوعيًا | فحص `/api/health`، واستهلاك الحصة في Ollama وGemini |
| شهريًا | التحقق من روابط جهات الإحالة في `muhawir/referrals.py` (الرئاسة العامة للبحوث العلمية والإفتاء) وأنها ما زالت تعمل، ثم إعادة بناء قاعدة المصادر (تطلب الموسوعة القرآنية إبقاء النسخ محدّثة)، وتحديث المكتبات، وإعادة التقييم |

## تحديث المتجهات بعد تغيير المصادر

البحث بالمعنى (المتجهات) مفعّل على خادم Oracle بالإعداد `MUHAWIR_VECTORS=1` في `~/muhawir.env`. فهرس المتجهات مرتبط بقائمة المقاطع: إذا تغيرت المصادر وأُعيد بناء قاعدة البيانات، وجب بناء فهرس جديد، وإلا رجع البحث إلى الكلمات وحدها.

1. **بناء الفهرس على Kaggle** (معالج رسومي مجاني، نحو 90 دقيقة): دفتر `muhawir-notebook` بخلية واحدة تنزّل المستودع وتبني قاعدة البيانات والمتجهات، وتخرج `muhawir-vectors.tar.gz`. ملف «بينات» مرفوع في الدفتر مجموعةَ بيانات خاصة (Private)، لأن موقع dawa.center يمنع التنزيل الآلي. افتح الدفتر ثم Save Version ← Save & Run All، وتأكد في السجل أن عدد المقاطع يساوي عدد مقاطع الخادم.
2. **جلبه إلى الخادم بأمر واحد** (الخادم هو الذي يجلب الملف من Kaggle، فلا يُحفظ مفتاح الخادم في أي موقع خارجي):
   ```
   cd ~/muhawir && scripts/fetch_vectors.sh <اسم-المستخدم-في-Kaggle>/muhawir-notebook
   ```
   يتحقق الأمر من أن معرّفات المقاطع في الفهرس تطابق قاعدة البيانات واحدًا واحدًا وبالترتيب؛ فإن لم تتطابق لم يغيّر شيئًا. ويحفظ الفهرس السابق في `data/vectors.previous/`، ويعيد تشغيل الخدمة.
3. **مرة واحدة قبل أول استعمال:** في kaggle.com ← Settings ← API ← Create New Token، فينزل ملف `kaggle.json`. انسخه إلى الخادم:
   ```
   mkdir -p ~/.kaggle && mv kaggle.json ~/.kaggle/ && chmod 600 ~/.kaggle/kaggle.json
   ```
   هذا المفتاح يقرأ حساب Kaggle فقط، ولا يُرفع إلى المستودع.

وللإطفاء: اجعل السطر `MUHAWIR_VECTORS=` في `~/muhawir.env` ثم أعد تشغيل الخدمة؛ فيعمل مُحاور بالبحث بالكلمات وحده.

## مراجعة المحتوى

| المسؤول | المهمة |
|---|---|
| مختص شرعي | يراجع قائمة أسئلة التقييم في [EVALUATION.md](../EVALUATION.md) قبل تجميدها، ثم عينة من 20 جوابًا شهريًا: صحة النسبة والمعنى، وسلامة الامتناع والإحالة |
| المشغّل | يصلح ما تكشفه المراجعة في الشيفرة أو التعليمات، ويعيد التقييم، ويوثق الخطأ وإصلاحه في سجل الإيداعات |

المفاتيح في ملف إعدادات على الخادم وفي لوحة Render فقط، لا في المستودع. والخادم لا يحفظ الأسئلة ولا بيانات المستخدمين.
