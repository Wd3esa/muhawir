# تشغيل واحد للجودة والزمن والكلفة

طلب المشغّل جمع الخطوات المتبقية في دفعة واحدة. الأداة
`scripts/run_acceptance_batch.py` تعرض الخطة فقط افتراضيًا. خيار `--execute`
ينفذ خمس طلبات فعلية للخدمة المحلية: واحدًا منفردًا ثم أربعة مختلفة متزامنة.
لا يجرب الفاحص المجمّع ولا يغير الخدمة أو إعداداتها أو يمسح الإجابات المحفوظة.

تشمل الأسئلة التوكل والجماعة والحول وسؤالًا ذا جزأين وشرح الأمانة للصغار.
لكل سؤال معايير مراجعة مقترحة، لكن النتيجة الشرعية وتقييم الوضوح يظلان
معلقين حتى مراجعة الإجابات والنصوص الأصلية. لا تتحول HTTP 200 أو المطابقة
الآلية لمعرف المقطع إلى حكم بصحة الاستدلال.

يفحص البرنامج نسخة التطبيق وحجم القاعدة ووجود التتبع وإمكانية قراءة journal
بـsudo -n قبل طلب أي جواب. يحتفظ فقط بعلم التتبع وإعدادات غير سرية محددة
للتوازي والفهرس ومعرف النموذج، ولا يحتفظ ببيئة العملية كاملة أو مفاتيحها.
يثبت بصمات المصدر والمتجهات والفهرس خارج التوقيت.
هذا يسخن كاش ملفات النظام، ولا يثبت أن نموذج التضمين أو الإجابة بارد أو ساخن.

بعد الطلب الأول يتحقق من اكتمال سجل التكلفة والعمل الخلفي وبصمة الشيفرة.
يتوقف قبل الأربعة عند كلفة مجهولة أو سجل ناقص أو عتبة كلفة 0.10 دولار.
**هذه ليست ميزانية صلبة لدى المزود:** الأربعة التالية تبدأ معًا وقد تنتهي
وتُحاسب كلها. حد الخمس لطلبات الإجابة، وليس لنداءات النموذج الداخلية.
لا إعادة HTTP ولا تعويض تلقائي لطلب فشل أو انتهت مهلته. انقطاع انتظار
العميل لا يوقف عمل الخادم، والمفقود لا يحسب صفر تكلفة أو نجاحًا.

يضم ملف JSON خاص واحد إجابات العميل كاملةً، وأزمنته المحلية، وسجلات التتبع
الخاصة بمعرفاته فقط بعد ضم العمل المتأخر، والتكاليف المبلغة، وتصنيف الكاش،
والنصوص الأصلية للمقاطع المستشهد بها من القاعدة للقراءة دون تعديلها، وحالة
الخدمة قبل وبعد. يفصل اكتمال كلفة الدفعة عن اكتمال الكلفة في السجلات المرصودة
فقط؛ لا ينسب أحداث زوار آخرين إلى الاختبار. MemoryPeak ذروة عمر الخدمة،
لا ذروة هذه الدفعة وحدها. التوقيت لاستجابة HTTP المحلية الكاملة وليس لرسم
المتصفح أو شبكة الزائر. تُفصل توزيعات الوقت للمنفرد والمتزامن، ولأن الأسئلة
والأساليب مختلفة لا يستنتج منها أثر سببي للتزامن أو تحسن مقابل القياسات القديمة.
عينة الأربعة لا تثبت سعة تشغيل مستدامة أو p95 عامًا. اسم المزود في التتبع
يصف ناقل الاتصال المهيأ؛ قد لا يسجل مزود OpenRouter الخلفي، فلا يُخمن اسمه.

يحفظ ملف التقرير 0600 ويحدثه بعد كل استجابة حتى لا تضيع الإجابات إذا تعذر
استخراج السجلات. تمنع علامة تشغيل ثابتة إعادة الدفعة بالخطأ. لا تزلها لمجرد
ظهور خطأ؛ اقرأ التقرير أولًا. لا بيانات خاصة أو أجوبة أو مفاتيح في Git.
